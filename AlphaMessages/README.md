# AlphaMessages

Стартовый проект для Paper 1.21.11 / Java 21.

## Сборка
`mvn -U -f AlphaMessages/pom.xml clean package`

## Команды
- `/am reload`
- `/am plugins`
- `/am editor`
- `/am version`

Право: `alphamessages.admin` (по умолчанию OP).

## Текущий статус
Реализовано ядро: конфиги, команды, GUI-индикатор и обнаружение выбранных плагинов.
Автоматическая замена всех сообщений сторонних плагинов ещё не реализована. Для этого нужны отдельные адаптеры под конкретные версии/API; каждый адаптер должен пройти тестирование.
